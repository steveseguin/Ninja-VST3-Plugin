WebRTC VST Setup Guide

REAPER-first setup steps plus generic VST3 host instructions.

Download for Windows Mac — Apple Silicon Mac — Intel Back To Main Page

1) Install on Windows

A

Preferred: run webrtc_vst-windows-setup.exe.

B

Manual: extract webrtc_vst.vst3 from the zip.

C

Install path: %LOCALAPPDATA%\Programs\Common\VST3\.

1) Install on Mac

A

Download the Apple Silicon DMG for a native Apple Silicon DAW, or the Intel DMG for an Intel Mac or a DAW running under Rosetta. Requires macOS 11 or later.

B

Open the DMG. In Finder, use Go > Go to Folder and enter ~/Library/Audio/Plug-Ins/VST3/. Create the folder if needed and copy the entire webrtc_vst.vst3 bundle into it, then eject the disk image.

C

Restart your DAW and rescan its VST3 plugins. Add VDO.Ninja WebRTC Bridge to a track. Logic Pro and GarageBand cannot load VST3 plugins.

The v0.2.5 Mac DMGs are Developer ID signed, Apple-notarized, and carry stapled approval tickets. REAPER send/receive and saved-project reopening have been validated on Mac. Other Mac DAWs and macOS 11 still need manual validation. Do not disable Gatekeeper to install the plugin.

2) REAPER Setup

1

Open REAPER's Preferences > Plug-ins > VST. Preferences is under Options on Windows and the REAPER menu on Mac.

2

Windows: ensure the path includes %LOCALAPPDATA%\Programs\Common\VST3. Mac: install in ~/Library/Audio/Plug-Ins/VST3/, the standard user VST3 folder.

3

Click Re-scan (or Clear cache/re-scan).

3) Play Mode (Receive Audio)

1

Add plugin to a track and set mode to Play.

2

Enter Stream ID (example: wBYPUKL).

3

Enable track monitor, confirm REAPER meter activity.

4) Seed Mode (Publish Audio)

1

Set mode to Seed.

2

Set a Stream ID and play audio on that track.

3

Open your VDO.Ninja viewer URL and confirm audio arrives.

Troubleshooting

Plugin not visible

Rescan VST3 in REAPER and confirm plugin path is correct.

No audio in Play mode

Confirm Stream ID and Password match publisher settings exactly.

No audio in Seed mode

Confirm track has signal and the stream is being viewed remotely.
