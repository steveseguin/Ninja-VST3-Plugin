Why this plugin

Audio-first by design

Play mode requests audio transport only, so video tracks are ignored inside the VST workflow.

Two practical modes

Seed mode publishes your DAW audio. Play mode monitors remote audio inside the same session.

Production codec path

Opus transport, stereo support, and DAW-friendly routing for real-time collaboration and review.

Quick start

1

Install the latest `.vst3` package from the release assets below.

2

Load the plugin in a real-time DAW host (Reaper/Studio One recommended for validation).

3

Set mode to Seed to publish or Play to receive a remote stream.
