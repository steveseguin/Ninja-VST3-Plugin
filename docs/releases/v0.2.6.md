# v0.2.6 — Windows audio and host compatibility fixes

This Windows release improves playback continuity and restores the editor when
a host loads the plugin binary without its external layout resource.

## Changes

- Preserve the unconsumed part of an Opus concealment frame, preventing small
  host buffers from advancing concealment too quickly after packet loss.
- Use a precise private Windows worker timer to avoid observed playback
  underruns caused by long one-millisecond sleeps.
- Preserve fractional resampler tails and size incoming peer buffers correctly
  at high host sample rates.
- Embed the Windows editor layout as a fallback for missing external resources.
- Improve audio-test pacing and analyzer accuracy; add loss/jitter regressions,
  REAPER validation, and an application media gallery.

## Validation

The downloaded, signed Windows plugin passed nine native CI checks, the full
JavaScript integration gate, live-room audio, and a five-minute strict stereo
soak with **zero silent blocks among 54,520 measured steady blocks**, including
two deliberate signaling interruptions. Steinberg's validator reported
**47 passes and no failures**. REAPER 7.82 passed sustained Play/Publish, bypass
recovery, saved-project restoration, fresh-process loading and offline render
checks. Audacity 3.7.9 passed five editor open/close cycles; Audacity 4.0.1 passed
five fresh plugin-registration scans. Both Mac source CI builds also passed.

A separate 45-second strict quality probe measured 66.15 ms local p95 latency,
0.96 ms marker spread, and no silent, clipped or nonfinite blocks. Tone residuals
passed the unchanged median/p95 limits. Earlier source-build validation also
covered REAPER at 44.1, 48 and 96 kHz and Ableton Live 12.4.6.

The installer completed successfully and installed the exact same plugin as
the ZIP. Completed VirusTotal scans reported zero malicious or suspicious
detections for both packages. SHA-256 checksums are attached.

## Install and limits

Use the Windows x64 installer, or extract the ZIP and install the entire
`webrtc_vst.vst3` folder into `%LOCALAPPDATA%\Programs\Common\VST3\`.
Restart/rescan the DAW. Hosts that require the system folder can use
`C:\Program Files\Common Files\VST3\` with administrator permission.

Both Windows binaries are signed as Social Stream Ninja / Steve Seguin and
DigiCert-timestamped. The validation machine reports an untrusted signing
root; Windows may show a trust/reputation warning.

Requires a VST3 host using 32-bit float processing. FEC remains disabled;
packet reordering and adaptive jitter handling remain areas for improvement.
Record remote audio in real time before offline export.

This release contains Windows packages. The existing [notarized macOS v0.2.5
builds](https://github.com/steveseguin/Ninja-VST3-Plugin/releases/tag/mac-v0.2.5)
remain available. New Mac source is CI-tested, but v0.2.6 Mac distribution still
requires Developer ID signing, notarization and host validation.
